    Mtk-51

    GJS TypeScript type definitions for Mtk-51 using ts-for-gir v4.3.0.

    Install

    Install the type definitions with npm:

    npm install @girs/mtk-51

    Usage

    Import it like any other module:

    import Mtk from '@girs/mtk-51';

    Ambient Modules

    Ambient modules let you write the same import you would in plain JavaScript. For this you need to include @girs/mtk-51 or @girs/mtk-51/ambient in your tsconfig or entry point Typescript file:

    index.ts:

    import '@girs/mtk-51'

    tsconfig.json:

    {
      "compilerOptions": {
        ...
      },
      "include": ["@girs/mtk-51"],
      ...
    }

    The ambient module now resolves with types:

    import Mtk from 'gi://Mtk?version=51';

    Global import

    GJS's global imports.gi works too, with types. For this you need to include @girs/mtk-51 or @girs/mtk-51/import in your tsconfig or entry point Typescript file:

    index.ts:

    import '@girs/mtk-51'

    tsconfig.json:

    {
      "compilerOptions": {
        ...
      },
      "include": ["@girs/mtk-51"],
      ...
    }

    That form carries types as well:

    const Mtk = imports.gi.Mtk;

    Bundle

    Most projects want a bundler. esbuild is the smallest thing that works; the examples directory has setups for several others.

    All existing pre-generated packages can be found on gjsify/types.
